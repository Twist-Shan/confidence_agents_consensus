# 平衡 L2 题库：40 题 Luna 校准结果

运行日期：2026-09-18。20260921 是题库 seed，不是运行日期。

结论：本轮达到预先规定的探索性难度阈值，可以作为设计下一步小规模 confidence 实验的依据；不能据此宣称模型内部置信度已校准或 confidence 干预有效。输出截断造成部分 root 不完整，正式讨论实验前需要先解决并复核。

## 题库与执行

题库为 data/logic-l2-balanced-20260921.json，40 道独立 L2 题，每题 7 个布尔变量、28 个三文字析取子句。“蕴含/不蕴含”各 20 题，每类正确选项 A/B 各 10 题。题面、真值及验证信息均经精确求解器核验，与此前运行的 problem 对象不重复。

从 seed=20260921 的固定候选序列依次取每类最先出现的 20 个独立题目，共检查 113 个候选。筛选只用精确语义真值；没有使用模型输出，也没有删除难题或重采样到出现分歧。冻结文件保存全部候选取舍审计。生成分布已改为两类等权，不能把与此前非平衡题库的总体准确率差异视为模型能力变化。

每题六次独立回答，无同伴信息或 confidence 干预。模型请求 ID 为 openai/gpt-5.6-luna，全部 240 次响应报告供应商 OpenAI。沿用原提示词、供应商默认推理参数及 2,048 输出 token 上限，四题并发。没有开启结构化输出约束。

- 240 次调用完成。
- 230 条有效响应，其中 186 条正确、44 条错误。
- 10 条无效响应：2 条格式/解析失败、8 条输出截断。保持原失败规则，不修补或重新请求。
- API usage 费用合计 **0.3142284 USD**，无缺失费用字段；最终以 OpenRouter 账单为准。
- 首次推理请求至末次响应约 627.9 秒，即 10 分 28 秒，不含准备和目录检查。

## 主要结果

| 指标 | 结果 |
|---|---:|
| 有效回答正确率 | 186/230 = 80.9% |
| 先题内计算有效正确率、再题间等权平均 | 80.6% |
| 无效响应比例 | 10/240 = 4.17% |
| 六次回答全部有效的题 | 32/40 |
| 六次有效回答存在对错分歧的题 | 15/40 = 37.5% |
| 完整题中有分歧的比例 | 15/32 = 46.9% |
| 六次全对的题 | 17/40 |
| 至少一次无效响应的题 | 8/40 = 20% |
| 六次有效回答全错的题 | 0/40 |

预先规定的规则是：有效回答正确率 30%–85%、无效率不超过 10%、至少一个完整六回答组有分歧。本轮满足，因此 summary.json 的 recommended_exploratory=true。该标志是工程上的探索性筛选，不是显著性检验或正式实验质量认证。

“有分歧”要求六次回答全部有效；不完整组中可能也有对错差异，但未计入这 15 题。每题只采了一组六次回答，37.5% 不是某道题的稳定分歧概率。不能将 240 次回答当成 240 个独立题目。

## 按语义答案分层

| 正确语义答案 | 题数 | 正确/有效响应 | 正确率 | 无效响应 | 完整组分歧题/全部题 |
|---|---:|---:|---:|---:|---:|
| 蕴含（Yes） | 20 | 72/112 | 64.3% | 8 | 12/20 |
| 不蕴含（No） | 20 | 114/118 | 96.6% | 2 | 3/20 |

两类各占一半，始终回答 Yes 或 No 的完整题库基线均为 50%。本轮分歧和错误更多集中在“蕴含”题；这是对该平衡题库的观察，不能仅凭此确定模型错误机制。

| No/A | 10 | 56/60 | 93.3% | 0 | 3 |

各格是不同题目，不能把格间差异直接归因为 A/B 位置效应；要识别位置效应，需要同一底层题目的配对换位设计并按底层题聚类。

## 错误回答的自报置信度

将 p_B 转换为“所选答案的自报概率”：选 B 时为 p_B，选 A 时为 1-p_B。

- 44 条有效错误回答的这一数值均不低于 0.99。
- 平均为 0.9960。
- 逐条错误答案和原始理由保存于 wrong_answers.json。

这支持后续研究“高自报置信度的错误”，但只是模型在当前提示下报告的数值，并非经过验证的内部信念或正确率。当前实验分配给其他 agent 的展示分数与这个私有 p_B 是两个变量，尚未测量相互影响。

## 下一步

可以据此设计小规模局部重放 L，但在进入持续讨论 C 前应优先处理输出可靠性：本轮调用级无效率虽只有 4.17%，却使 20% 的题目无法形成完整 root。8 次截断与当前输出上限有关；使用结构化输出可约束格式，但不能保证消除推理耗尽 token 的问题。提高上限或改变推理设置会改变实验条件，应在新配置、新运行目录中复核，不静默修补本轮。

保留全部 40 题及所有失败，不仅挑选这 15 道分歧题来报告效果。正式采样应重新生成独立初始回答，统一冻结题库和模型配置；若再次依据本轮结果挑题，必须标记为探索性选择。校准结论只对应 Luna，本轮不支持 GLM/Qwen 的难度结论。

本轮未启动 confidence 干预、未替换默认 pilot 题库。详情见 manifest.json、summary.json、diagnostics.json、wrong_answers.json、invalid_responses.json 和 items/。
