# Luna 难度校准：第一轮探索结果

日期：2026-09-18。结论：优先复核逻辑蕴含 L1、L2；不将本轮筛选结果视为已经验证的正式题库。

## 运行与规则

- 模型：openai/gpt-5.6-luna。144 次响应均报告供应商 OpenAI。
- 3 类题 × 4 个生成复杂度等级 × 2 道题 × 6 次独立回答 = 144 次请求。
- 并发 4 个题目，每题内部串行，执行顺序预先随机化；无置信度处理、无同伴答案、无按结果重采样。
- 每次最多 2,048 输出 token；推理强度等参数使用供应商默认值，与前次 smoke 一致。
- 首次请求至末次完成约 270 秒。API usage 累计费用 0.1280004 USD，无缺失费用；以实际账单为准。
- 139 条有效回答，130 条正确；5 条无效：4 条 JSON 格式问题、1 条输出截断。无效不计为错误或分歧。
- 开跑前固定的推荐规则：题型×等级层面，有效回答正确率 30%–85%，无效率不超过 10%，至少一题的 6 条有效回答中同时存在正确与错误答案。

## 解释与边界

1. 生成等级并非已知难度。L3、L4 更大的公式在本轮反而更易回答；随机实例结构、问题方向和题目数量都可能影响结果，尚不能确定原因。
2. 每层仅两个题、每题六次回答，正确率和分歧率很不稳定。推荐是探索性选择，不是难度估计已经收敛。
3. JSON 转义失败集中于带数学表达式的理由；应在后续新版本中使用结构化输出并单独复核，不能静默修复本轮答案后重新筛题。输出预算也可能影响难度，变更预算后需要重新校准。
4. 结果只对应本轮 Luna 配置，不能直接推广到 GLM 或 Qwen。模型别名和默认推理设置仍可能漂移；正式实验应进一步固定配置。
5. 已按新 seed 20260919 生成推荐两层的四道独立题，保存在 holdout_candidates.json，未进行模型调用，状态为 unvalidated。原 run 命令仍使用原开发题库。

## 下一步实验设计

先在新题上独立复核推荐难度，再冻结正式题库。正式 confidence 对照需要固定同一题的自身答案、同伴答案及顺序，改变展示分数；在多道题上重复，并按题目聚合。

局部重放 L 固定所有答案内容，仅改变分数。多轮讨论 C 共享初始回答及邻居顺序；后续回答允许受到干预而分化，比较的是整段动态过程的结果。不要为了保持后续答案相同而覆盖模型响应。

本轮校准回答不能直接作为筛选后正式确认性实验的独立证据。不得重复采样某题直到出现指定的对错比例；保留一致回答及所有失败记录。
